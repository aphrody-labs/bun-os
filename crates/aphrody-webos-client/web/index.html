Engineering Foundation

Built from source. Engineered for sovereignty.

Aphrody rejects bloated layers and fragile wrappers. Every component is audited, built from source, and coordinated under a unified Rust and Bun architecture.

Bun OS Base & Rust Kernel

Linux 7.4-rc1 mainline with Rust module support, binderfs, memfd, and KVM acceleration. Native system services written in Rust with memory safety by default.

COSMIC Shell & libcosmic

Hardware-accelerated Wayland desktop shell written in Rust using iced. Butter-smooth 120Hz frame pacing with adaptive window tiling and workspace segregation.

WebOS Streaming Gateway

Zero-install instant streaming protocol. Direct WebSocket binary frame bridge with WebCodecs hardware decoding and low-latency input event transport.

Gemini Agentic Subsystem

Context-aware intelligence wired into Spacedrive files, Rio terminal commands, and system search without telemetry or cloud tracking.

Material 3 Color Harmony

Harmonized themes. Calm by design.

Derived directly from Material 3 tonal spot palettes. Switch themes to see your workspace adapt instantly with optimal contrast and deep OLED focus.
