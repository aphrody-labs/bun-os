## Default Permission

Attach a native 3D layer to the calling window and drive its scene, model, viewport and camera.

#### This default permission set includes the following:

- `allow-attach`
- `allow-detach`
- `allow-set-scene`
- `allow-load-model`
- `allow-set-viewport`
- `allow-orbit`
- `allow-info`
