# Bun OS Store (Flutter)

Flutter Material 3 front of the Bun OS Store and WebOS server APIs (`/api/store/catalog`, `/api/health`) for
Android, Linux desktop and web. Theme: `lib/theme/bunos_tokens.g.dart`, generated by
`bun packages/m3-os-themes/src/cli.ts apps` from the same tokens as the web, Compose and COSMIC themes. Rust core:
`crates/bunos-flutter-bridge` through flutter_rust_bridge (M3 schemes for any seed). Build and toolchain:
[docs/ANDROID.md](../../docs/ANDROID.md).
