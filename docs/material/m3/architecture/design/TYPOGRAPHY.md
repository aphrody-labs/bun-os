# Typography

Who owns Material 3 typography in Aphrody. Spec values: the M3 type scale
(<https://m3.material.io/styles/typography/type-scale-tokens>) as encoded in
`crates/aphrody-m3-tokens/src/typography.rs`; do not copy the table elsewhere.

## Owners

| Concern | Owner | Consumers |
| --- | --- | --- |
| Type scale (15 baseline roles) | `crates/aphrody-m3-tokens/src/typography.rs` | `sheets.rs` (`--text-*` in `packages/m3-theme/tailwind.css`), `aphrody-render` via `aphrody_m3_tokens::facade::typography` |
| Runtime `--md-sys-typescale-*` CSS | `@aphrody/m3-tokens` (`../packages/m3-tokens`, `m3-tokens.css`) | `@aphrody/m3-theme`, `@aphrody/material-web` `md-typescale-styles` |
| Google Sans Flex axes | `crates/aphrody-m3-tokens/src/google_sans_flex.rs` (mirrored in `packages/material-web/typography/internal/google-sans-flex-axes.ts`) | `<md-type>`, native renderer |
| Expressive axes per role (`opsz`, `GRAD`, `ROND`) and emphasized roles | `packages/material-web/typography/internal/type-scale.ts` | `<md-type>`, `typeStyleCss`, `typeScaleVars` |
| Font files, subsets, `@font-face`, stacks, fallbacks | `@aphrody/m3-fonts` ([`FONTS-AND-ICONS.md`](./FONTS-AND-ICONS.md)) | `@aphrody/app-ui`, the `@aphrody/m3` plugin |

Do not add another type-scale table or `@font-face` block: import from the owner. `fonts.css` is
generated by `bun run gen` in `packages/m3-fonts`; its test fails on drift.

Emphasized roles keep size, line height and tracking and raise the weight (500 for display,
headline, title-large and body; 700 for title-medium, title-small and label). Display, headline
and title-large use `md.ref.typeface.brand`; the other roles use `md.ref.typeface.plain`.

## Typefaces and axes

Axis ranges are read from the `fvar` tables of the shipped files.

| Family | Role | Axes |
| --- | --- | --- |
| Google Sans Flex | brand / UI | `wght` 1-1000, `opsz` 6-144, `wdth` 25-151, `GRAD` 0-100, `ROND` 0-100, `slnt` -10-0 |
| Google Sans Code | code | `wght` 300-800, `MONO` 0-1 |
| Roboto Flex | plain fallback | `wght` 100-1000, `opsz` 8-144, `wdth` 25-151, `GRAD` -200-150, `slnt` -10-0 |
| Roboto Mono | code fallback | `wght` 100-700 |
| Noto Sans JP | Japanese fallback | `wght` 100-900, kana/CJK/full-width `unicode-range` |
| M PLUS 1 Code | Japanese code fallback | `wght` 100-700 |

`@aphrody/m3-fonts` exports the stacks as `--aphrody-font-{brand,plain,code,icon}`: the Latin face
first, the Japanese face only for glyphs the Latin face lacks.

Google Sans Flex: let `opsz` follow the rendered size; use `GRAD`, not `wght`, for emphasis that
must not reflow (hover, dark theme); keep `ROND` at 0 for body text.
