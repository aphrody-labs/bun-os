# Aphrody brand colours

Brand colour roles are generated, never hand-written. Contract:
[`APHRODY-M3-CANONICAL-CONTRACT.md`](./APHRODY-M3-CANONICAL-CONTRACT.md).

## Desktop app

`packages/app-ui/src/brand-theme.ts` (not in repo) renders `src/brand.css` from `BRAND_SEED = "#17335C"`
(the measured seed of `aphrody-identity`, `design --m3-seed`) with
`@aphrody/m3-tokens/dynamic-color` `cssFromSeed`. Dark is the default (`:root`, `.dark`);
light is `.light`. Change the seed at the source, then regenerate; never edit `brand.css`.

## Rust constants

`crates/aphrody-m3-tokens/src/color.rs` defines `APHRODY` (light) and `APHRODY_DARK` (dark, the
default for native Aphrody surfaces): `SchemeTonalSpot` roles of the legacy seed `#CE422B`.
The full light and dark role sets are in [`aphrody-m3-theme.json`](./aphrody-m3-theme.json),
generated by `@material/material-color-utilities`. Additions beyond core M3 (for example a
`success` role) are M3 extended colours (`--md-ext-color-*`), not ad-hoc hex values.
