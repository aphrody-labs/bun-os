`cdn.aphrody.com` is the CDN origin of the monorepo's UI design assets and AI
brand assets, and nothing else. Game assets are not served here: nie publishes decoded assets on its single
host, `nie.aphrody.com/cdn/` (2026-09-23). The former `aphrody-assets.inc`, which aliased the
raw game install publicly, is removed.

| Path | Content | Cache |
| --- | --- | --- |
| `/s/<scope>/<path>` | stable URL of a repository asset | 1 h, stale-while-revalidate 1 d |
| `/h/<sha16>.<ext>` | content-addressed copy | immutable, 1 year |
| `/s/manifest.json` | every file: sha256, size, type, hashed URL | 60 s |

Scopes come from [`tools/config/asset-catalog.json`](../../../../../tools/aphrody/config/asset-catalog.json):

| Scope | Source | Owns |
| --- | --- | --- |
| `os` | `aphrody/assets/ui` | Material 3 design references and UI captures (scope name kept so `/s/os/` URLs stay stable) |
| `os` | `material/crates/m3-tokens/fonts`, mounted at `fonts/` | Google Sans fonts and OFL notices; `/s/os/fonts/` stays stable |
| `os` | `material/packages/m3-fonts/fonts/web`, mounted at `fonts/web/` | Google Sans Flex web WOFF2 used by `aphrody-fonts.css` |
| `aphrody` | `aphrody/assets/ai` | agent brand (Byron), product captures and renders |
| `aphrody` | `aphrody/crates/ui/identity/assets/brand`, mounted at `brand/` | logo and favicon set generated by `aphrody-identity` (`favicon.ico`, `icon.svg`, PNG 16-1024, maskable, `apple-touch-icon.png`, `site.webmanifest`, wordmarks, `m3-tokens.{css,json}`, `aphrody-fonts.css`, `aphrody-logo.css`) |

## Rules

- One owner per file content. A copy of the same bytes in another catalogued source fails
  `cdn:check`; reference the owner's CDN URL or its path in this monorepo instead
  of copying it. The UI, web and system layers do not publish the AI brand source.
- Only tracked files are served (`git ls-files`), PSD sources excluded.
- Code uses `https://cdn.aphrody.com/h/...` for long-lived references (read the hash from
  `/s/manifest.json`) and `/s/...` for URLs that should follow the latest release.

## Operate

```sh
bun scripts/aphrody/tools/infra/cdn.ts check            # sources present, no cross-source duplicate
bun scripts/aphrody/tools/infra/cdn.ts build            # build/cdn/release: s/, h/, s/manifest.json, RELEASE_SHA
bun scripts/aphrody/tools/infra/cdn.ts publish --vps vps [--dry-run]   # --vps local when run on the vps
```

`publish` copies the release to `/home/ubuntu/apps/cdn/releases/<RELEASE_SHA>` (`rsync -aH`, which
keeps the `s/`/`h/` hardlinks; from Windows a tar stream over ssh) and switches
`/home/ubuntu/apps/cdn/current` atomically; the previous release stays for rollback (switch the link
back). Builds run on the vps: build and publish there from a checkout of the repository with `--vps local`.

Serving on dbfr: `aphrody-fonts-proxy` (`tools/config/host/systemd/aphrody/aphrody-fonts-proxy.service`,
`127.0.0.1:8796`) answers `/h/` and `/s/` from its `--static` roots (catalog release first, then
the Material Symbols release) with the cache, type and CORS headers above, before its Google Fonts
proxy. The gateway vhost is `zz-cdn.aphrody.com.conf` under `tools/config/host/nginx/` in the
`aphrody-gateway-1` container: `docker exec aphrody-gateway-1 nginx -t`, then `nginx -s reload`.
The root path answers 404.

## Material Symbols

Owned by the fork `aphrody-labs/material-design-icons`, branch `aphrody` (checkout
`~/src/forks/material-design-icons` on vps), not by a catalog source: the release is built there and
published as its own static root, listed in `asset-catalog.json` `releases`.

| URL | Content | Cache |
| --- | --- | --- |
| `/s/symbols/material-symbols.css` | `@font-face` Outlined, Rounded, Sharp (variable WOFF2, `font-display: block`) and the Google classes `.material-symbols-{outlined,rounded,sharp}` | 1 h, stale-while-revalidate 1 d |
| `/s/symbols/release.json` | commit, symbol count, URL, size and sha256 of every file | 1 h |
| `/h/<sha16>.{css,woff2,ttf}` | the CSS, the web WOFF2 and the desktop TTF of each style | immutable, 1 year |

```sh
# in ~/src/forks/material-design-icons (vps)
bun run build && bun run check
bun run cdn build && bun run cdn publish --host dbfr && bun run cdn verify
```

`publish` rsyncs `dist/cdn` to `/home/ubuntu/apps/cdn/symbols/releases/<id>` on dbfr and switches
`/home/ubuntu/apps/cdn/symbols/current`; `aphrody-fonts-proxy` serves it as its second `--static` root,
after the catalog release `/home/ubuntu/apps/cdn/current`. Rollback: point `current` back to the previous
release directory. Then update the `releases` entry of `asset-catalog.json` (commit, id, URLs, sha256).
