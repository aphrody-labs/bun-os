# Buv GPU and PyJS native qualification — 2026-10-10

The canonical `aphrody_ffi` provider now targets cudarc 0.19.10's CUDA 13.4
bindings. Its existing `gpu,cuda` features retain the default tooling exports.
No separate Yolo dynamic library is introduced. On Windows, the shared wgpu
hub prefers D3D12 when the same class of GPU exposes multiple backends;
the existing discrete NVIDIA preference still takes priority over backend.
Other platforms keep their prior selection order.

## Native evidence

`clippy --locked -p aphrody-gpu-backend --all-targets --features hub,cuda --

zero unit tests; the hardware consumers provide the behavioral evidence.

including the opt-in combined PyCUDA/Buv GPU case and native Cython/Nuitka

## Reproduction

Resolve the selected Bun/Aphrody checkouts and the native artifact paths from
the host configuration. Set `BUV_RUNTIME_LIB` to the canonical DLL;
`BUN_PYTHON_EXECUTABLE`, `BUN_PYTHON_HOST_LIBRARY`, `BUN_PYTHON_LIBPYTHON` and
`PYTHONPATH` identify the qualified CPython host and PyCUDA venv. Set
`CUDA_PATH` to the isolated toolkit and prepend its `bin/x64` (not in repo) and
`bin` (not in repo) to the process PATH. Use the qualified MSVC 14.44 environment.

```text
BUN_TEST_PYCUDA=1 BUN_TEST_BUV_GPU=1 PYCUDA_DISABLE_CACHE=1 BUV_TEST_PYTHON_COMPILER=1
bun bd test test/js/first_party/runtime/python-cli.test.ts
```

The environment assignment above describes process-local variables; use the
selected shell's syntax. Cudarc's version is selected by the manifest, without
a `CUDARC_CUDA_VERSION` override that would activate conflicting bindings.

## Limits

This qualifies native Windows GPU consumption, not a published release asset,
an installed default provider, Linux/ARM GPU hardware or production activation.
The wgpu hub is shared through the canonical provider; PyCUDA owns a separate
CUDA context and allocations. No zero-copy interop, shared PyCUDA/wgpu buffers,
cross-provider singleton, performance improvement or memory reduction is claimed.
CUDA driver compatibility below 13.4 remains a separate qualification.
The scoped documentation link gate checked 27 documents and 30 local links
without a broken link. The global `docs:check` gate remains nonzero on stale
generated workspace/root/ecosystem/documentation indexes; it is not certified
by this receipt, and concurrent generated documents were not overwritten.
The workspace contains concurrent changes, so the DLL hash identifies the tested
artifact and does not certify every workspace product or reproducible packaging.
