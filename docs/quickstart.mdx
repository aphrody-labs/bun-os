## Requirements declared by the repository

Use the Aphrody runtime selected by the repository guidance in `AGENTS.md`;
`bun agent-plugin doctor --json` checks its runtime provenance. The runtime
installer and upgrade command are documented there. `rust-toolchain.toml`
declares the Rust toolchain for the root Cargo workspace. Git is required by
source and submodule commands. Other native tools depend on the build target.

## Inspect setup inputs

```bash
bun run setup --plan
```

This prints a read-only source and vendor preflight. It does not install
dependencies or qualify the workspace.

## Inspect a factory plan

```bash
bun src/cli.ts factory arch --action plan --composition server --snapshot YYYY-MM-DD
bun src/cli.ts workspace graph --profile full --target linux-x64
```

These commands request a plan and graph for a declared composition. The
snapshot date is an input; it does not identify a built image. The checked-in
`distribution.json` currently labels qualification as `development`.

For setup behavior, see [the root README](../README.md). For the product and
source map, see [the Bun OS repository map](REPOSITORY-MAP.md) and
[`docs/PRODUCT.md`](PRODUCT.md). For factory inputs and qualification
boundaries, see [the distribution architecture](/architecture/arch-distribution).
