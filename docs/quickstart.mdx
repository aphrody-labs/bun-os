## Requirements declared by the repository

The root package manifest declares Bun `1.4.4`; `rust-toolchain.toml` declares
the Rust toolchain used by the root Cargo workspace. Git is required by source
and submodule commands. Other native tools depend on the selected build target.

## Inspect setup inputs

```bash
bun run setup --plan
```

This prints a read-only source and vendor preflight. It does not install
dependencies or qualify the workspace.

## Inspect a factory plan

```bash
bun src/cli.ts factory --action plan --composition server --snapshot YYYY-MM-DD
bun src/cli.ts graph --composition server
```

These commands request a plan and graph for a declared composition. The
snapshot date is an input; it does not identify a built image. The checked-in
`distribution.json` currently labels qualification as `development`.

For setup behavior, see [the root README](https://github.com/aphrody-labs/bun-os/blob/os/README.md).
For factory inputs and qualification boundaries, see
[the Arch distribution architecture](/architecture/arch-distribution).
