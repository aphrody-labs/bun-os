This repository contains the Bun OS distribution workspace. The root CLI is
`src/cli.ts`; distribution selectors are declared in `distribution.json`, and
pinned source revisions are recorded in `sources.lock.json` and Git submodule
gitlinks.

The manifests describe intended sources, profiles, targets and compositions.
They do not by themselves prove that a package set, image, application or
hardware target builds, boots or is release-qualified. The distribution
manifest currently labels qualification as `development`.

## Declared compositions

`distribution.json` declares `server`, `desktop` and `gaming` compositions,
with `null`, `cosmic-session` and `gamescope` session values respectively. These
are configuration values, not evidence that the compositions have been built
or qualified.

## Workspace state

- `package.json` declares the root Bun workspace.
- `Cargo.toml` declares a root Cargo workspace, but also excludes source trees;
  nested Cargo workspace boundaries remain. Cargo consolidation is incomplete.
- The runtime is unmodified upstream Bun, pinned to npm `bun@1.4.4-canary.20261028.1` (gitHead `11c367163a4b`). The former `toolchains/bun` fork submodule was removed.
- `factory/`, `src/`, `crates/`, `packages/`, `apps/` and `vendor/` contain
  product, tooling and imported source. Directory presence alone does not prove
  ownership, workspace membership or qualification.
