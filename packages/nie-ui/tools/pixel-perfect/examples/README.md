# Pixel-perfect examples

Static reference pages used by the pixel-perfect tooling to compare Bun OS M3 renderings:

| Page | Shows |
|---|---|
| `aphrody-terminal-demo.html` | the LLM-first terminal layout (sub-agent pane, MCP status, hook events, NDJSON) |
| `gemini-clone-pixel-perfect.html` | a Gemini chat layout; the Gemini brand gradients and sparkle logo are content |
| `m3-shadcn-pixel-perfect.html` | the 12 shadcn-equivalent components in Material Web, light and dark panes |
| `m3-shadcn-pixel-perfect-v2.html` | the 30-component matrix of the same comparison |

Every chrome colour, shape, type and motion value comes from the canonical sheets generated by
`crates/aphrody-m3-tokens`: `@aphrody/m3-theme/tokens.css` (roles, light and dark),
`@aphrody/m3-theme/tailwind.css` (extended success and warning roles) and
`@aphrody/m3-tokens/m3-tokens.css` (shape, type, motion, elevation, state). Fonts and Material Symbols
come from `@aphrody/m3-fonts`. The pages link these files relatively, so serve the `packages/` directory:

```sh
bun x serve packages
```

Then open, for example, <http://localhost:3000/nie-ui/tools/pixel-perfect/examples/aphrody-terminal-demo.html>.
