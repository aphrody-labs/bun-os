O OSC aphrody-* namespace

14 reserved sequences · spec §LLM-extension

Single OSC namespace reserved by docs/design/aphrody-terminal-spec.md for LLM-aware extensions. All sequences follow the form \e]aphrody-<name>;<payload>\a.

  • aphrody-md — render markdown block inline
  • aphrody-json — surface JSON in inspect panel
  • aphrody-sub-agent — sub-agent status update
  • aphrody-mcp — MCP server activity
  • aphrody-hook — hook firing log entry
  • aphrody-skill — skill invocation log
  • aphrody-task — task tree update
  • aphrody-browser-nav — navigate active browser to URL
  • aphrody-browser-eval — eval JS in browser, response via JSON pane
  • aphrody-browser-dom — query DOM (CSS selector), surface result tree
  • aphrody-browser-screenshot — capture viewport / element / full-page
  • aphrody-browser-intercept — install request interception rule
  • aphrody-browser-extract — structured extraction (schema-driven)
  • aphrody-browser-perf — perf timing emission for the active page
