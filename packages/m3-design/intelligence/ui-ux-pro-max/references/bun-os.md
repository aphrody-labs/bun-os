# Bun OS / Aphrody UI ecosystem

Map of the UI owners in the Bun OS workspace (`aphrody-labs/bun-distribution`, branch `os`). Paths are
repository-relative. Search the matching data with `--stack m3`, `--stack rg-ui`, `--stack nextjs`,
`--stack html-tailwind`, `--stack shadcn` and the `brands.csv` palette rows.

## Which layer to use

| Building                                           | Use                                                                                       | Why                                                                                                                 |
| -------------------------------------------------- | ----------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| Rose Griffon, Azalée or Achilléa web surfaces      | `@rosegriffon/ui` (`packages/rg-ui`) + `@rosegriffon/app-shell` (`packages/rg-app-shell`) | Owns the five chrome themes, the shadcn bridge, Base UI components and the shared navigation chrome                 |
| A new Aphrody/Bun app without a Rose Griffon brand | `@aphrody/m3*` (`packages/m3*`)                                                           | Material 3 tokens, Tailwind preset, Base UI wrappers, Next 16 integration, all generated from `crates/aphrody-m3-tokens` |
| A web-component UI (Lit, `md-*`)                   | `@aphrody/material-web` fork (`vendor/material-web`) + `@aphrody/m3-react`                | 119 `md-*` elements with React wrappers                                                                             |
| Any Tailwind v4 build on Bun                       | `@aphrody/bun-plugin-tailwind` (`toolchains/bun/packages/bun-plugin-tailwind`)            | `Bun.build`, `Bun.serve` HTML imports, dev server and a PostCSS entry for Next; `theme: "m3"` preset                |

rg-ui is itself built on the M3 tokens (`@aphrody/m3-tokens` dependency): its themes declare
`--md-sys-color-*` roles and map shadcn variables onto them, so both vocabularies work inside it.

## Packages

### Material 3 (`packages/`)

- `m3-tokens`: `m3-tokens.css` (shape, typescale, motion, elevation, state layers), `expressive.css`,
  `breakpoints.css` (600/840/1200/1600 width classes, `@custom-media --md-*`), `dynamic-color`
  (`schemeFromSeed`, `cssFromSeed`, `applyDynamicColor`, `clearDynamicColor`), `platform-contract`
  (`platformState(widthDp)`). Generated from `crates/aphrody-m3-tokens/src/sheets.rs`; never hand-edit.
- `m3-tailwind`: CSS-first `preset.css` (49 colour roles, `rounded-*`/`shape-*`, `text-<role>`,
  `shadow-elevation-0..5`, easings/durations/springs, `state-layer`, `compact:`..`extra-large:`,
  Base UI `m3-open:`/`m3-highlighted:`... variants). Import order: `tailwindcss`, `m3-tokens.css`,
  `expressive.css`, `preset.css`.
- `m3-theme`: `tokens.css` (baseline seed `#6750A4`, M3 roles + shadcn aliases + Tailwind
  `@theme inline`), `tailwind.css`, `spaceui.css`.
- `m3-next`: `withM3` config, `M3Root`/`M3Html` (themed first byte, `color-scheme`, pre-paint
  script), `createM3Proxy` for `proxy.ts`, client theme provider, Tauri static export, `m3-next`
  runner (Next on Bun).
- `m3-baseui`: 38 Base UI primitives with M3 classes (`M3Button` variants filled/tonal/outlined/
  text/elevated, sizes xs..xl; compose with `render`).
- `m3-react`: React wrappers for the 119 `md-*` elements (`MdFilledButton`, `MdIcon`...).
- `m3-icons` (inline SVG Material Symbols; client bundles use `./browser` + `m3:icon/<style>/<name>`),
  `m3-fonts` (Google Sans Flex/Code, Roboto Flex/Mono, Material Symbols, JP fallbacks),
  `m3-motion` (container transform, shared axis, fade through), `eslint-plugin-m3`
  (`valid-color-role`, `require-icon-button-label`... under `bun lint` jsPlugins),
  `m3` (framework: plugin, `serveM3`, `buildM3`, `m3` CLI), `m3-bun`, `m3-os-themes`.

### Rose Griffon (`packages/rg-ui`, `packages/rg-app-shell`)

- `src/styles.css`: imports `brands.css`; `@theme inline` bridge of M3 roles to Tailwind
  utilities, brand tokens (`bg-rg-marine`, `text-rg-or`, `bg-rg-brique`), semantic states
  (`succes`/`info`/`alerte` + `on-*`), game constants (`element-*`, `poste-*`), third-party
  brand colours, `type-*` typescale, `text-fluid-*`, `state-layer`, `motion-*`, focus and
  forced-colors outline, `prefers-reduced-motion` guard for smooth scrolling.
- `src/brands.css`: generated by `scripts/tools/rg-m3.ts` (seeds `#e91e63`, `#f89c5a`,
  `#6d00ce`). It is **unlayered**, so its Azalée and Achilléa roles override the hand-written
  `@layer base` blocks of `styles.css`.
- `src/tokens.ts`: generated hex projection of the seven themes for Canvas/Discord/scripts
  (`bun packages/rg-ui/scripts/generer-tokens.ts`).
- Components on Base UI (`button.tsx`, `sidebar.tsx`, `responsive-dialog.tsx`...): `data-slot`
  hooks, `asChild` adapted to `render` (`src/lib/render.tsx`), focus
  `focus-visible:ring-[3px] ring-ring/50 outline-hidden`.
- `rg-app-shell`: `AppSidebar`, `WikiSidebar`, `TopAppBar`, `NavigationRail`, `MobileBottomNav`,
  `Footer`, `ThemeToggle`, navigation/route config and chrome metrics (`HAUTEURS`).

## Themes and selectors

| Brand ID (brands.csv)          | Selector                                                                   | Scheme       | Source of effective values                                |
| ------------------------------ | -------------------------------------------------------------------------- | ------------ | --------------------------------------------------------- |
| `rose-griffon-roy`             | `.theme-roy`, `.roy`                                                       | light        | `packages/rg-ui/src/styles.css` (default of rg-website)   |
| `rose-griffon-gaelle`          | `.theme-gaelle`, `.gaelle`                                                 | light        | `packages/rg-ui/src/styles.css`                           |
| `rose-griffon-light` / `-dark` | `.theme-rg`, `.theme-rg-dark`                                              | light / dark | `packages/rg-ui/src/brands.css` (not in the switcher yet) |
| `azalee-light` / `azalee-dark` | `.theme-azalee-light`/`.azalee-light`, `.theme-azalee-dark`/`.azalee-dark` | light / dark | `packages/rg-ui/src/brands.css`                           |
| `achillea`                     | `.theme-achillea`, `.achillea`                                             | dark         | `packages/rg-ui/src/brands.css`                           |
| `m3-baseline-light` / `-dark`  | `:root`, `.dark`                                                           | light / dark | `packages/m3-theme/tokens.css`                            |

- The class goes on `<html>`; an inline script first in `<head>` (`SCRIPT_THEME`,
  `apps/rg-website/src/app/layout.tsx`) applies the `rg-theme` value before paint, then
  `ThemeProvider` (`next-themes`, attribute `class`, `enableSystem: false`) takes over.
- Section identity goes on the content container (`theme-azalee-dark` under `/wiki`,
  `theme-achillea` under `/achillea`, `apps/rg-website/src/app/client-layout.tsx`); never
  `setTheme` on navigation. Nested themes paint themselves via `:where(.theme-x:not(:root))`.
- Every theme sets `color-scheme`. App `:root` defaults must stay in `@layer base`.
- `dark:` must be extended: `@custom-variant dark (&:is(.dark, .dark *, .azalee-dark, .azalee-dark *, .theme-azalee-dark, .theme-azalee-dark *));`

Fonts: rg-website loads Roboto (body) and Poppins (headings) with `next/font`
(`apps/rg-website/src/lib/fonts.ts`), Noto Sans and Lato with `preload: false` for the Azalée
scope; Achilléa uses `@font-face` families in `apps/rg-website/src/app/achillea/achillea.css`
(Inter body, HUMANE titles, Liberation Mono); azalee-web declares Google Sans Flex in
`--font-sans` and Geist Mono; M3 reference typefaces are Google Sans Flex / Google Sans Code.

## Tailwind v4 wiring

```css
/* apps/rg-website/src/app/globals.css */
@import "tailwindcss" source("../.."); /* the build may run from the monorepo root */
@import "@rosegriffon/ui/styles.css";
@source "../../../../packages/rg-ui/src"; /* symlinked workspace sources are not detected */
@source "../../../../packages/rg-app-shell/src";
@plugin "@tailwindcss/typography";
```

`apps/azalee-web/app/globals.css` uses `@import "tailwindcss" source(none);` with an explicit
`@source` list and a `data-slot` width fallback for the sidebar. Both apps compile through
`@aphrody/bun-plugin-tailwind/postcss` (`postcss.config.mjs`).

## Next.js 16 on Bun

- Next is the `aphrody-labs/next.js` fork (`next 16.5.0-canary.5`, root `package.json` override);
  run it with `@aphrody/next-bun` (`next-bun dev|start`, builds through
  `scripts/iecode/rg/next-build.ts`). `bunfig.toml` sets `env = false` so Next loads its own env files.
- `proxy.ts` (not `middleware.ts`) with a narrow literal matcher and optimistic cookie checks
  (`apps/rg-website/src/proxy.ts`).
- `next.config.ts`: `reactCompiler: true`, `transpilePackages` for workspace sources,
  `optimizePackageImports` for barrels, `outputFileTracingRoot`/`turbopack.root` at the repo root
  for standalone output.
- LCP: `fetchPriority="high"` + `loading="eager"` on the first hero image only; `priority` is
  deprecated in Next 16 (`preload` replaces it).
- Read `node_modules/next/dist/docs/` for the installed version before writing Next code
  (`apps/rg-website/AGENTS.md`).

## Accessibility defaults

Visible focus with a forced-colors outline (`CanvasText`), `prefers-reduced-motion` gating in
consumers (rg-ui only gates smooth scrolling), `color-scheme` per theme, 44px touch targets,
`aria-current="page"` in navigation, no zoom lock in `viewport`, and Baseline widely available
features by default (newer features behind `@supports`).
