# @aphrody/craft-ui

Elite 2026 UI/UX design engineering tokens, OKLCH dynamics, WebGPU glass shaders, and luxury component primitives for Aphrody, Bun OS, and the 14 Craft Pro studios.

## Features
- **OKLCH Color Dynamics**: 49 semantic color roles with perceptual uniformity, wide-gamut Display P3 support, and contrast ratio validation.
- **Multi-Layered Elevation Depth**: Hairline specular bevels (`1px inset rgba(255,255,255,0.09)`) combined with multi-stop ambient occlusion.
- **WebGPU WGSL Glass Shaders**: Real-time transmission, chromatic aberration, micro-surface roughness, and procedural fallback to Canvas2D.
- **Spring Physics**: Damped harmonic oscillator simulation (`stiffness: 400`, `damping: 30`) and CSS `linear()` timing generation.
- **Luxury React Components**: `GlassPanel`, `StudioToolbar`, `DockableTabGroup`, `VelocityButton`, `MetricBadge`.
